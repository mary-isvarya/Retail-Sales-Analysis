# Retail Sales Analysis

## Project Overview

This project focuses on analysing retail sales data to understand
sales performance, customer purchasing behaviour, and product trends.

The project uses Python for data cleaning and exploratory data
analysis and Power BI for interactive dashboard development.

## Problem Statement

The objective is to analyse retail transaction data to identify
sales patterns, customer preferences, and product performance.
The findings can help businesses make better data-driven decisions.

## Dataset Description

- Dataset: Retail Sales Dataset
- Total Records: 1,000
- Original Columns: 7
- Domain: Retail Analytics

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Git and GitHub
## Data Cleaning and Preparation

The dataset was inspected and prepared using Python and Pandas.

The following operations were performed:

1. Removed the unnecessary index column.
2. Checked for missing values.
3. Checked and removed duplicate records.
4. Converted the Date column into datetime format.
5. Extracted Year, Month, Month Number, Day and Day Name.
6. Checked numerical columns for outliers using the IQR method.
7. Saved the prepared dataset as retail_sales.csv.

### Data Quality Results

- Total Records: 1,000
- Missing Values: 0
- Duplicate Records: 0
- Outliers Detected: 0
- Final Dataset: retail_sales.csv

## Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to identify patterns, trends, and insights in the retail sales dataset.

The analysis included:

1. Gender-wise sales analysis.
2. Age group-wise customer analysis.
3. Product category-wise sales analysis.
4. Monthly sales trend analysis.
5. Daily sales analysis.
6. Quantity sold analysis.
7. Revenue analysis.
8. Identification of top-performing categories and customer segments.

Pandas and Matplotlib were used to analyze and visualize the dataset.

## Key Insights

The analysis revealed the following key insights:

1. Identified the highest revenue-generating product category.
2. Analyzed sales distribution across male and female customers.
3. Identified the most active customer age group.
4. Examined monthly revenue patterns.
5. Identified top-performing sales segments.
6. Analyzed customer purchasing behavior based on quantity and total amount.

These insights help understand customer preferences and retail sales performance.

## Conclusion

This Retail Sales Analysis project helped explore customer purchasing behavior and identify important sales trends using Python.

Data cleaning, preparation, exploratory data analysis, and visualization were performed to extract meaningful insights from the dataset.

The project demonstrates practical skills in Python, Pandas, NumPy, Matplotlib, data analysis, and data visualization.

The insights obtained can help businesses understand customer preferences and make data-driven decisions.
